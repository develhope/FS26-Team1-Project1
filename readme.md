# Lego Website Redesign

A frontend redesign of the official Lego website, focusing on modern UI/UX principles.

## Overview

This project is a faithful recreation of the Lego website using HTML, CSS with Flexbox layouts.

## Features

- Responsive design
- Modern CSS with Flexbox
- Interactive elements
- Clean and user-friendly interface

## Tech Stack

- HTML5
- CSS (Flexbox)


## Getting Started
```bash
# Clone the repository
git clone https://github.com/develhope/FS26-Team1-Project1.git

# Navigate to project folder
cd FS26-Team1-Project1

# Install dependencies
npm install

# Start development server
npm run dev
```
